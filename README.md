# Ripple Effect

Click anywhere on the page and a white circle ripples outward from the cursor.

## What it does
- On each click, `ripple.js` creates a `div` at the cursor position and plays a short CSS animation (0.4 s) that grows it to 150 px and fades it out.
- The purple background and the animation keyframes are in the HTML file's `<style>` block.

## Run it
Open `ripple.html` in a browser and click the purple area.

## Files
- `ripple.html` - page and CSS
- `ripple.js` - click handler that creates the ripple element
